# Temporarily Shelved Development

This directory is the single home for JARVIS work that is intentionally paused and is **not part of the active 2.2.1 Beta release path**.

## Currently shelved

All paused development belongs here as one centralized temporary-development area. Active 2.2.1 Beta runtime code remains in its normal platform directories; paused concepts, packaging tracks, and future-only work are documented or stored here.

### Google Play distribution

Google Play publishing is temporarily shelved while the project focuses on direct beta distribution and a dependable Windows installer.

When resumed, Play-specific packaging, publishing notes, store-readiness work, and related development should be managed from this area instead of being mixed into the active direct-beta path.

## Rule for future shelved work

Do not create separate top-level shelved/paused/experimental holding folders. Move or document temporarily paused development here so there is one obvious place to find it.

Items should return to their normal active project locations when development resumes.
