# JARVIS V2.2 release scope

## Active V2.2 work

V2.2 focuses on a stable synchronized Windows and Android release:

- shared Windows, Android Play, and Android Direct version identity
- safe cross-edition settings export and import
- local chat, coding, and image engines
- required Direct-edition model and service provisioning
- optional Play-edition model packs
- phone-only verified updater
- Windows-to-Android compatibility
- lint, unit, security, lifecycle, packaging, signing, and migration verification
- installable Android and Windows release artifacts

## Deferred after V2.2

Payment and entitlement work is intentionally out of scope for V2.2 and must not block the V2.2 release:

- Google Play Billing
- Direct-edition checkout
- purchase restoration
- paid-edition entitlement verification
- signed offline entitlement leases
- license renewal and expiration
- payment-security testing
- paywalls and purchase prompts

Do not implement, enable, or expose incomplete payment functionality in V2.2. Preserve payment-related design work for a later release. A future release must restore its own payment-specific implementation, security, and validation gates before distribution.
