# Old development

This folder is reserved for clearly obsolete development artifacts that are no longer required by the current JARVIS release.

## Archive policy

Before moving anything here, confirm that it is not referenced by:

- the Android or Windows build workflows
- the Android app or Windows host
- the Windows installer
- documentation
- tests

Historical versions of active files should remain in Git history instead of being copied here. The current v0.3.1 tree was reviewed on 2026-08-14; no files were moved because every tracked path supports the current app, builds, installer, documentation, or tests.
